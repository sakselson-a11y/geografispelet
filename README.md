# Blindkarta

Geografispel för mobilen. Välj världsdel och antal länder, tryck sedan på kartan där landet ligger. Rätt svar blir grönt och ligger kvar. När omgången är slut ser du resultatet och kan visa facit.

Spela: https://sakselson-a11y.github.io/geografispelet/

Lägg till på iPhone: öppna länken i Safari → Dela → Lägg till på hemskärmen.

Kartdata: Natural Earth (via world-atlas), public domain.
